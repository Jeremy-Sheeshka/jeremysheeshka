      <p><b>Initial Thoughts:</b><br>
      For my Playing with Design project, I chose a metronome as my object and built an interactive guide using Twine. It allowed me to use HTML, CSS, and JavaScript to create a step-by-step learning process for introductory musicians.</p>

      <p><b>Affordances and Constraints:</b><br>
      Twine's "choose-your-own-adventure" style was perfect for a guided manual. I used the SugarCube format to handle complex audio scripting, allowing for a cowbell, snare, and triangle to play in real-time without lag.</p>

      <p><b>Problem Solving:</b><br>
      A major challenge was audio overlapping. Harlowe was too restrictive, but switching to SugarCube resolved the latency issues. I also decided to link to the HTML file directly rather than using an iframe to ensure the layout stayed responsive.</p>

      <p><b>Pedagogical Perspectives:</b><br>
      This project balances <b>Instructionism</b> (structured steps) with <b>Constructivism</b> (experimental exploration). Users build self-confidence by adjusting parameters and hearing the results immediately.</p>
