# Rhythm Reader — AI Workflow Playbook

## Your Setup
- **MiMo Code** — full agentic, running right now in this terminal
- **Reasonix + DeepSeek** — full agentic, configured in this repo (`.reasonix/`)
- **Claude Code** — online, strongest general model
- **Qwen 3.8** — online, fast/cheap

## The Project
Rhythm Reader is a music sight-reading game built on Astro 6. Key pieces:
- `public/games/rhythm-reader/` — the interactive games (Free Play, Rhythm Bank, Co-op, Dinosaur mode)
- `fp-onboard.js` — the main overlay engine (notation renderer, tap judging, audio, draw layer)
- `netlify/functions/` — Firebase-backed rhythm storage
- `src/` — the Astro blog/portfolio site that hosts it
- Deployed on Netlify, auto-deploys on push to main

## Concrete Workflows

### 1. Adding a New Feature (e.g. new game mode, new rhythm pattern)

```
Step 1 — DESIGN in DeepSeek/Reasonix
  "I want to add [feature] to Rhythm Reader. Here's how fp-onboard.js works:
   [paste relevant section]. Design the implementation approach."
  → DeepSeek reasons through architecture, edge cases, data flow

Step 2 — PLAN in MiMo Code
  "Implement [feature] based on this design: [paste DeepSeek's output]"
  → MiMo Code creates a plan, you review it

Step 3 — BUILD in MiMo Code
  MiMo Code implements the feature:
  - Reads existing code
  - Makes edits
  - Runs `pnpm build` to verify
  - Tests in browser

Step 4 — REVIEW in DeepSeek
  "Review this diff for correctness: [paste git diff]"
  → DeepSeek catches edge cases MiMo might miss

Step 5 — FIX + DEPLOY in MiMo Code
  Apply review feedback, commit, push (auto-deploys to Netlify)
```

### 2. Debugging a Tricky Issue (e.g. cursor misalignment, tap timing off)

```
Step 1 — REPRODUCE in MiMo Code
  "The cursor jumps at barlines when in 4-bar mode"
  → MiMo Code reads the relevant code, traces the logic

Step 2 — ANALYZE in DeepSeek
  "Here's cursorX() and pos(). The cursor jumps at barlines.
   [paste the functions]. What's the root cause?"
  → DeepSeek's reasoning strength finds the math issue

Step 3 — FIX in MiMo Code
  Apply the fix DeepSeek identified
  → MiMo Code edits, builds, verifies

Step 4 — VERIFY in MiMo Code
  Test the fix, check for regressions
```

### 3. Refactoring fp-onboard.js (it's complex, ~1000+ lines)

```
Step 1 — UNDERSTAND in MiMo Code
  "Map out the structure of fp-onboard.js — what are the main
   sections, functions, and their dependencies?"
  → MiMo Code reads and summarizes

Step 2 — PLAN in DeepSeek
  "Here's the structure of fp-onboard.js. I want to extract
   [notation renderer / audio engine / tap judge] into a module.
   Design the refactoring approach."
  → DeepSeek designs clean module boundaries

Step 3 — EXECUTE in MiMo Code
  Full-file rewrite as HANDOFF.md recommends (not micro-edits)
  → MiMo Code rewrites, builds, verifies

Step 4 — REVIEW in DeepSeek
  "Did I preserve all the safety rails? Review this refactor."
  → DeepSeek checks against HANDOFF.md constraints
```

### 4. Writing a Blog Post About the Project

```
Step 1 — OUTLINE in DeepSeek
  "I want to write about how Rhythm Reader works for my EdTech blog.
   Here's the HANDOFF.md. Outline a post."
  → DeepSeek structures the argument

Step 2 — DRAFT in DeepSeek
  Flesh out each section, maintain your voice (per STYLE_GUIDE.md)

Step 3 — FORMAT + PUBLISH in MiMo Code
  "Turn this draft into an MDX post in src/content/post/"
  → MiMo Code creates the file, runs build, pushes
```

### 5. Schoolwork — EdTech Course Assignments (ETEC 531)

```
For WRITTEN work:
  DeepSeek first — "Help me analyze [concept] in the context of Rhythm Reader"
  Claude Code for polish — "Improve this draft, maintain academic voice"

For CODED work:
  MiMo Code — implement, test, iterate
  DeepSeek — review for correctness

For RESEARCH:
  MiMo Code — "Search arxiv for papers on rhythm training and sight-reading"
  DeepSeek — "Synthesize these 3 papers into a literature review section"
```

### 6. Quick Fixes (CSS, copy, config)

```
Just use MiMo Code directly:
  "The navbar gear icon is too small on mobile"
  "Update the Free Play gate copy to say X"
  "Fix the spacing on the Rhythm Bank cards"
  → No need for DeepSeek on small changes
```

### 7. Firebase / Netlify Functions Issues

```
Step 1 — MiMo Code: read the function code, check logs
Step 2 — DeepSeek: "Here's the function and the error. What's wrong?"
Step 3 — MiMo Code: apply fix, push, test on live site
```

## Decision Matrix for This Project

| Task | Use This | Why |
|---|---|---|
| Small CSS/HTML fix | MiMo Code | Fast, direct |
| New game feature | DeepSeek → MiMo Code | Think first, build second |
| Tap timing bug | DeepSeek | Math/reasoning strength |
| Cursor alignment | DeepSeek | Spatial reasoning |
| Refactor fp-onboard.js | DeepSeek plan → MiMo Code execute | Both needed |
| Blog post writing | DeepSeek → Claude Code | DeepSeek drafts, Claude polishes |
| Rhythm Bank feature | MiMo Code | File-heavy, iterative |
| Build/deploy | MiMo Code | Only one with git access here |
| "Why isn't this working?" | MiMo Code first | Read code, check build |
| Architecture decision | DeepSeek | Stronger on tradeoff analysis |
| Quick question | MiMo Code | Fast, no context switch |

## What Each Tool Uniquely Gives You on This Project

### MiMo Code
- **Direct file access** — reads/writes your actual code
- **Build verification** — runs `pnpm build`, catches errors immediately
- **Git integration** — commit, push, auto-deploy
- **Memory** — remembers HANDOFF.md constraints, past bugs, your preferences
- **Browser testing** — can start dev server, you test in browser

### DeepSeek (via Reasonix)
- **Math reasoning** — tap windows, cursor math, grid calculations
- **Architecture thinking** — module boundaries, data flow design
- **Code review** — catches edge cases in complex logic
- **Second opinion** — when MiMo's output doesn't feel right
- **Learning support** — explains concepts for your coursework

### Claude Code (online)
- **Polish** — best at refined writing and clean code
- **Hard problems** — when both MiMo and DeepSeek are stuck
- **Nuanced refactoring** — judgment calls on complex changes

### Qwen 3.8 (online)
- **Quick lookups** — "what does this CSS property do?"
- **Multilingual** — if you need content in other languages
- **Cheap tasks** — don't waste premium tokens on simple questions

## Recommended Daily Workflow

```
Morning: Start MiMo Code for the day's implementation work
  ↓
Hard problem appears? Switch to DeepSeek/Reasonix for analysis
  ↓
Come back to MiMo Code with the solution
  ↓
Need polish or stuck? Escalate to Claude Code
  ↓
Quick question? Qwen if the others are busy
```

The key insight: **MiMo Code is your workstation, DeepSeek is your thinking partner.** Use them together, not in isolation.
